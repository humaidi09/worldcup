# World Cup 2026 Simulator

Simulate the 2026 FIFA World Cup: run the group stage, advance through the
knockouts, and play the tournament out to a champion. A front-end simulator you
can re-run as many times as you like.

**Live demo:** https://humaidi.me/worldcup/

## Built with

React 19 · Vite · Tailwind CSS v4 · React Router · Zustand · Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL (the app is served under `/worldcup/`). Build for
production with `npm run build`.
